Computer networking protocols operate across standardized layered models: the 7-layer OSI Model and the 4-layer TCP/IP Model.

OSI 7-Layer Architecture:
1. Physical Layer: Transmits raw bits over physical media (cables, radio waves, optical fibers).
2. Data Link Layer: Node-to-node frame delivery using Media Access Control (MAC) addresses; handles framing, error detection (CRC), and flow control (e.g., Ethernet IEEE 802.3, Wi-Fi 802.11).
3. Network Layer: End-to-end packet routing across intermediate networks using logical IP addresses (e.g., IPv4, IPv6, ICMP, routing protocols BGP, OSPF).
4. Transport Layer: Host-to-host process communication, multiplexing ports, and reliability (e.g., TCP, UDP).
5. Session Layer: Manages sessions, dialogs, and checkpoints between applications.
6. Presentation Layer: Data syntax translation, serialization, compression, and encryption/decryption (e.g., TLS, ASCII, UTF-8).
7. Application Layer: High-level network protocols providing user services (e.g., HTTP, HTTPS, DNS, SSH, FTP, SMTP).

Transmission Control Protocol (TCP):
- TCP is a core protocol of the Internet Protocol suite operating at the Transport layer (Layer 4).
- TCP is a connection-oriented, reliable transport protocol. It provides full-duplex, in-order, and error-checked delivery of a byte stream between communicating endpoints.
- Establishing a TCP connection requires a formal three-way handshake:
  1. SYN: Client sends a synchronize sequence number packet.
  2. SYN-ACK: Server responds acknowledging the client's packet with an acknowledgement number and sends its own SYN.
  3. ACK: Client sends an acknowledgement confirming connection establishment.
- TCP implements flow control (sliding window mechanism) and congestion control (Slow Start, Congestion Avoidance, Fast Retransmit, and Fast Recovery). Connection termination uses a four-way handshake (FIN, ACK, FIN, ACK).

User Datagram Protocol (UDP):
- UDP is a connectionless, lightweight transport protocol.
- UDP sends independent message packets called datagrams without establishing a prior connection, handshake, or session state.
- UDP does not use or establish a three-way handshake. It provides no guarantees of delivery, ordering, packet duplicate elimination, or congestion control. This absence of overhead yields low latency, making UDP optimal for real-time applications such as VoIP, live video streaming, DNS lookups, and multiplayer online gaming.

Domain Name System (DNS):
- DNS is an Internet distributed directory service that translates human-readable domain names (such as www.example.com) into numerical IP addresses (such as 192.0.2.1 for IPv4 or 2001:db8::1 for IPv6).
- DNS queries predominantly use UDP port 53 for standard lookups and fall back to TCP port 53 for zone transfers or responses exceeding 512 bytes.

Hypertext Transfer Protocol (HTTP) and Status Codes:
- HTTP status codes are standardized three-digit integers returned by web servers indicating request outcomes:
  - 1xx (Informational): 101 Switching Protocols.
  - 2xx (Success): 200 OK (request succeeded, payload delivered), 201 Created, 204 No Content.
  - 3xx (Redirection): 301 Moved Permanently, 302 Found, 304 Not Modified.
  - 4xx (Client Error): 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found (indicates server cannot find requested resource; does not indicate success).
  - 5xx (Server Error): 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable, 504 Gateway Timeout.

Modern Web Protocols:
- HTTP/1.1: Uses persistent TCP connections but suffers from Head-of-Line (HoL) blocking on pipelined requests.
- HTTP/2: Introduces binary framing, stream multiplexing over a single TCP connection, server push, and HPACK header compression.
- HTTP/3: Replaces TCP with QUIC (built over UDP), eliminating TCP HoL blocking and providing 0-RTT connection re-establishment with integrated TLS 1.3 encryption.
- HTTPS encrypts HTTP traffic using Transport Layer Security (TLS), employing asymmetric public-key cryptography (RSA or ECDHE) for identity verification and session key negotiation, followed by symmetric block cipher encryption (such as AES-GCM or ChaCha20-Poly1305) for high-speed payload transfer.
